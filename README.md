# LIFE ROAD

ブラウザで遊べる3Dオンライン人生すごろく（2〜6人・オンライン対戦専用）。
`index.html` をブラウザで開くだけで遊べます（Three.js r128 / PeerJS を cdnjs から読み込み）。

- マス190（本線150＋分岐40）、職業22、アイテム20、家7、株10
- 3Dはすべて基本図形で構成、効果音はWeb Audioで合成

## オンライン対戦（P2P・ルームコード方式）
0. 最初にアバター（せいべつ・服の色・車の色）を選ぶ
1. 1人が「ルームを作る」を押し、表示された6桁コードを友だちに伝える
2. 友だちは同じページでコードを入力して「参加」（`?room=123456` 付きURLでも可）
3. 2人以上そろったらホストが「スタート」。途中で抜けた人は退出扱い（順位表に「退出」と表示）

ホストのブラウザがゲームを進行し、参加者へ表示と状態を配信します（ホストが閉じると終了）。
シグナリングは PeerJS 公開サーバー、回線が厳しい場合の中継は openrelay の公開TURNを使います（ベストエフォート）。

## テストモード（確認用）
待機ルームでホストが「🧪 テストモード」にチェック（または URL に `?test=1`）するとオン。1人でもスタートでき、ゲーム中に「🧪 テスト」パネルが使えます（ホストの自分だけに作用）。
- マスへジャンプ（結婚・ペット・分岐・家・退職・ゴールなど。そのマスの内容をすぐ実行）／マス番号の直接指定
- ルーレットの出目を固定、お金の増減、職業の変更、アイテムの追加

## マップの作り（地形と配置のルール）
- 地形は関数で決まります：陸 → 砂浜 → 浅瀬 → 海（波打つ海岸線）、川（水源の池 → マス95の橋 → 海）。
- 物を置くときは必ず `canPlace()` を通します（地形が合うか／道から「半径＋余白」離れているか／川から離れているか／ほかの物と重ならないか）。置いた物は台帳 `placed` に登録します。
- 乱数は固定シード（`WORLD_SEED`）なので、毎回同じマップになります。あとから建つ家も、順番が同じなら同じ場所に建ちます。
- 起動時に `checkWorld()` が自動で走り、console に「[LIFE ROAD] 配置チェック：… → 合計 0件」を出します（実物の大きさが登録した半径からはみ出していないかも照合）。
- 画質は端末で切り替えます（小さい画面やコア数の少ない端末は解像度と影を落とし、遅ければ影を自動でオフ）。
