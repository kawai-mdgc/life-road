# LIFE ROAD

ブラウザで遊べる3D人生すごろく（2〜6人・人間/CPU・オンライン対戦対応）。
`index.html` をブラウザで開くだけで遊べます（Three.js r128 / PeerJS を cdnjs から読み込み）。

- マス190（本線150＋分岐40）、職業22、アイテム20、家7、株10
- 3Dはすべて基本図形で構成、効果音はWeb Audioで合成

## オンライン対戦（P2P・ルームコード方式）
1. 1人が「🌐 オンライン対戦 → ルームを作る」を押し、表示された6桁コードを友だちに伝える
2. 友だちは同じページで「オンライン対戦」→ コードを入力して「参加」（`?room=123456` 付きURLでも可）
3. ホストが人数を決めて「スタート」。空き枠はCPU。途中で抜けた人はCPUに交代

ホストのブラウザがゲームを進行し、参加者へ表示と状態を配信します（ホストが閉じると終了）。
シグナリングは PeerJS 公開サーバー、回線が厳しい場合の中継は openrelay の公開TURNを使います（ベストエフォート）。

## 開発
`src/` が分割ソース。`src/build.sh` で `index.html` を再生成（`data.js` は `src/spec.txt` から自動生成）。
